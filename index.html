// 常见问题

01   你的专业背景是什么？ +
数字媒体艺术专业大三在读。这个专业教会我如何用设计思维去理解人和情感，而技术（无论是我自己操作还是通过 AI）是实现这些设计愿景的手段。
02   你不会编程，怎么做出这些项目？ +
我的开发方式是用 AI 工具（Claude Code 等）协作完成。我的角色是：定义产品方向、把控设计品质、做出技术选型、拆解复杂需求、测试和迭代。AI 负责代码实现，我负责"做什么"和"为什么这样做"。这种工作流让我一个人就能覆盖从前端到硬件到后端的产品全链路。
03   你目前在找什么样的机会？ +
2026 年暑期实习，方向为创意技术 / 交互设计 / 产品设计。特别感兴趣的是：交互装置设计、AI 原生产品设计、智能硬件体验设计——任何让技术和创意交叉的领域。
04   你的设计理念是什么？ +
好的设计应该触动情感。无论是银山香道的东方留白美学，还是情绪疗愈灯的光影呼吸，我都试图在人与物之间建立一种安静的对话。技术是隐形的，情感是显性的。
